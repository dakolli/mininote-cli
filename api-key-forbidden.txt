# api-key-forbidden.txt — RPC routes that API keys (mnk_...) cannot call.
#
# The generated client and CLI prune this surface by default so they expose only
# what a bare API key can reach; `gen`/`cmdgen -full` restores everything the
# introspect spec publishes. This file is a data snapshot (like intro.json), not
# code: change it and regenerate to change the surface.
#
# Format: one `Service.method` per line (exact case — methods are mixed case,
# e.g. Page.listPrefix). Blank lines and `#` comment lines are ignored.
#
# Seeded from the union of:
#   - every route the server answers 403 FORBIDDEN for API keys (403routes.txt),
#   - every Auth.* method (the client's sessionOnly map — key minting keys is
#     privilege escalation), and
#   - every Admin.* method (control plane, excluded wholesale).
#
# Refresh workflow: re-probe against a throwaway workspace with an API key
# (POST {"args":{}} to each route; 403 = key-blocked), record the new routes,
# regenerate. Never probe on real data. See README "Key-available surface".
#
